# Rendimento-escondido-no-estande-falhas-de-semeadura-no-milho-segunda-safra-do-norte-mato-grossense
Dados e códigos em Python do artigo "Rendimento escondido no estande": série da PAM/IBGE (2000–2020) para os 55 municípios do Norte Mato-grossense e simulação de Monte Carlo da perda de produção de milho por falhas de semeadura.
